# KRISHI: Knowledge-based Real-time Image Sensing for Harvest Insurance

KRISHI is an AI-powered crop analytics platform designed to modernize crop insurance loss assessment. By replacing manual, subjective field surveys with automated deep learning and geotagged image analytics, KRISHI accelerates claim settlements from months to under 5 days while reducing human bias and fraud.

---

### 🌟 Key Highlights
- **Offline-First Geotagged Capture:** Enables farmers to capture field images in low-connectivity areas with automatic background syncing once network access is restored.
- **Automated AI Damage Scoring:** Utilizes deep learning to identify crop types and quantify crop stress or loss automatically.
- **Anti-Fraud & Metadata Validation:** Prevents location spoofing and duplicate submissions via cryptographic geotagging.
- **Live Authority Dashboard:** Provides real-time regional health heatmaps and claim tracking for administrative bodies and insurers.
- **Gov-Tech Ready:** Designed for seamless integration into PMFBY workflows and national agriculture registries.

---

### 🛠️ Tech Stack
- **Mobile Frontend:** Flutter SDK, Dart
- **Web Dashboard:** React.js, Mapbox GL
- **Backend & APIs:** FastAPI, Pydantic v2, Uvicorn, REST APIs, WebSockets
- **Spatial Database & Storage:** PostgreSQL, PostGIS, AWS S3
- **AI & Analytics:** PyTorch, YOLOv8, OpenCV, Google Earth Engine
- **Deployment & Infrastructure:** Docker, AWS EC2, Render
